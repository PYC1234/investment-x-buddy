# 同一工作台内的资料问答

首页输入框下方添加 PDF / CSV（最多3份、每份3MB），输入自然语言问题后发送。没有附件时沿用原来的证券研究与审批流程；有附件时只分析明确附上的资料，回答和引用留在当前会话。原 `/documents` 与 `/documents.html` 入口自动回到首页，不再作为独立工具。

- 未登录可直接使用，默认不保存历史。附件和对话只存在页面内存，刷新后清空，不将原文件落盘。不同工作台线程各自持有附件和对话。
- AI 问答需明确勾选，向现有模型服务发送问题、筛选出的资料摘录、规则统计和最近三轮对话。默认关闭时仅返回规则提取，明确标识，不冒充语义问答。附件变动后不沿用旧附件的对话上下文。
- `/api/v1/documents/chat` 为无状态端点，不用外部线程ID寻找资料。每次重新提取本轮附件，证据使用文件前缀如 `[D1:R2]`、`[D2:P4-1]`，防止文件之间引用编号冲突。模型回复引用必须来自本轮提供的来源，引用合法性不代表事实已被全面核验。
- 登录用户可选择保存单轮问答及引用，通过既有个人历史下载/删除；不会自动保存附件或完整会话，不能刷新后直接恢复对话。仍受现有演示存储限制。
- 不是跨文件完整审计，未自动融合文件和联网行情，也不绕过原研究的审批。CSV统计来自完整有效列，PDF与摘要仅使用有限摘录；不同口径未对齐时不合并排名。

验证：`python -m pytest tests/test_document_chat.py tests/test_documents.py tests/test_identity.py -q`；前端 `npx tsx --test tests/identity.test.ts tests/research-gateway.test.ts` 与 `npm run build`。模型测试使用MockTransport检查上下文与引用，无外部模型费用。
