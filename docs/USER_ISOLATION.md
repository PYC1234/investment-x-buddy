# 个人工作区与记忆隔离

入口：`/account`。匿名可体验；注册独立用户名（不收集邮箱）后，可选择保存资料分析结果，查看自己的研究和偏好。

## 实现与边界

- 随机256位会话凭证，数据库只存SHA256摘要；密码使用独立随机盐和600000轮PBKDF2-HMAC-SHA256。不存明文密码。
- 凭证存浏览器sessionStorage，刷新后保留；关闭标签页后通常需要重新登录。不会保存密码。退出会吊销当前凭证。
- 匿名会话24小时、账号会话7天。新匿名会话会批量清理已过期、没有执行中任务的旧匿名记录。匿名历史不能迁移或自动绑定到新账号。
- 研究所有读取/执行/审批/取消/重试入口均按线程owner校验；资料历史查询和删除按owner校验。未认证返回401，跨账号和旧无归属数据返回404。
- 旧研究没有owner，保留在数据库但不向任何新用户开放，不允许凭ID自行认领。
- 账号只记住明确保存的研究偏好。当前规则规划器不会因此获得自主学习能力。没有跨文件自动RAG或自动学习纠正。
- 上传原文件不落盘；勾选保存时，原文摘录、结果和引用进入当前账号历史，最多50份。默认不保存。
- 研究删除会移除报告、任务、证据、事件、检查点和线程记忆；正在运行的任务需先结束或取消。清除记忆不删除历史报告。
- 认证接口有基本数据库限流。当前无密码找回、邮箱验证、多因素认证或管理员找回流程。
- 仍使用现有SQLite。若Render没有持久磁盘，账号和历史可能随重启/部署丢失；不能把本版称为已验证的跨重启长期存储。未创建付费资源。正式使用需先配置持久磁盘或外部数据库，并验证备份与恢复。

## 验收

1. 用A、B两个账号或两个独立浏览器上下文测试；只允许A看到A的历史、研究和偏好。
2. 将A的研究ID或历史ID交给B，用所有读取和修改端点请求，必须404。
3. A退出后，原token必须401；重新登录应返回不同token。
4. 匿名可以分析，但不能保存或查看账号历史。过期和伪造凭证必须401。
5. A删除分析后原ID必须404；删除研究后报告、证据、任务和记忆均不能再读取。
6. 在独立临时数据库跑测试，不向线上上传私密资料。部署后只用虚构CSV做隔离验收。
