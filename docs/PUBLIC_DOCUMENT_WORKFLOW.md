# 公开资料分析：基础版

入口：站点首页右下角「公开资料分析」，或 `/documents`。

## 本轮范围

- 真实上传CSV（UTF-8/GB18030）或文字型PDF；每份3MB，最多30页/5000记录/30列，一次3份。
- CSV：表头校验、缺失值计数、同列同单位最小/最大/均值及原记录编号。代码、日期不做数值统计，不跨不同口径拼接收益。
- PDF：提取按页原文，按关键词选择最多12段摘要证据；不将扫描件、复杂财务表格自动识别宣称为已完成。
- 下载Markdown和JSON：包含文件SHA256、引用、范围和缺失提示。文件内容不进入数据库或磁盘。
- 默认只做规则分析；选中AI摘要才向既有DeepSeek模型服务发送选中的文字。未配置模型/服务失败时显式提示，不以规则输出冒充模型调用。
- 模型引用编号只验证是否存在，不等于事实完全正确，生成内容必须人工复核。取消按钮中止浏览器等待，已发出的服务端/模型任务不保证立即停止。

## 部署

复用已有Netlify静态前端与Render FastAPI后端，不新建付费资源。

1. Render沿用 `backend` 工作目录与 `pip install -r requirements.txt` 构建命令；本次新增 `pypdf==6.21.4`。
2. Netlify沿用仓库 `netlify.toml` 的 `frontend/out`；沿用现有 `NEXT_PUBLIC_API_BASE_URL`，修改后须重新构建。
3. CORS保留实际前端域名。模型可选，沿用 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`，密钥只放后端。
4. 无鉴权的公开演示仅上传公开资料。生产部署仍需网关限流、鉴权、隔离与解析进程资源限额；不要用于敏感资料。

## 自测与实际验收

后端：`python -m pytest`；前端：`npm run typecheck`、`npm run lint`、`npm run build`。

1. 点击「使用示例数据」再「开始分析」，核对收益均值4.15%，费用均值0.53333%，收益缺失1条，产品代码未参与数值统计。示例是虚构数据。
2. 上传公开来源的真实CSV，核对20条预览、极值对应的记录、空值处理及原始单位；上传的数值不会被示例值替换。
3. 上传一份不超过30页、可复制文字的公开报告，按页核对证据摘录。扫描件应报需OCR，损坏文件应报错。
4. 上传两份资料，确认分别给出报告；不会将不同期间和口径自动混合。
5. 在明确同意模型处理后勾选AI摘要；模型未配置时要看到明确提示。查看AI引用并逐条人工核对。
6. 下载报告和结构化结果；刷新后文件和分析结果不应保留在服务器。

线上接口验收脚本（不调用模型）：`python verify_documents.py --base https://investment-x-buddy.onrender.com --pdf <公开基金资料概要PDF> --output <验收记录.json>`。PDF可使用招商基金公开的七页概要 `https://static.cmfchina.com/fundarticle/20260424/20022624403537.pdf`，核对第4页管理费0.60%的原文，不表示推荐该产品。

生产构建使用Webpack + Tailwind官方PostCSS插件，避开当前机器Turbopack CSS子进程异常；Next.js和eslint-config-next升级到16.4.3以修复构建检测到的旧版本漏洞。

不预先宣称节省多少时间。请用同一份真实资料记录人工整理耗时、工具耗时、复核耗时及错误/遗漏数，之后再形成面试案例。
